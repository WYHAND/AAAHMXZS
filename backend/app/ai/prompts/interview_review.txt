你的任务：给一次已经结束的模拟面试打分并生成复盘报告。

输入：
- 面试模式：{mode}（小测试 / 全真）
- 面试场景：{scene}（HR / 项目 / 技术）
- 目标岗位：{target_job}
- 问答记录（JSON，含每题的学生回答与追问回答）：{qa_json}
- 学生画像标签（JSON）：{profile_tags}

评分维度（每项 0-100，键名固定为下面 5 个）：
- 沟通表达：条理是否清晰、有没有跑题、语速与信息密度
- 逻辑思维：是否有结构化拆解、因果关系是否成立
- 专业基础：回答里体现的岗位相关知识与技能准确度
- 项目经验：能不能讲清背景、角色、难点、结果
- 求职动机：对岗位与行业的了解程度、规划的合理性

评分规则：
1. 严格按回答内容打分，答得少、答得空就给低分，不要给“鼓励分”。
   参考区间：完全没答 0-30；泛泛而谈 30-50；有细节但缺结果 50-70；有细节有结果 70-85；优秀 85-100。
2. overall_score 是 5 个维度的加权平均：沟通表达 0.2、逻辑思维 0.2、专业基础 0.25、项目经验 0.25、求职动机 0.1。
3. strengths 与 improvements 各 2-4 条，必须引用具体回答内容，不要写“表现不错”这类空话。
4. question_reviews 覆盖每一道题：
   - score 按该题表现给（0-100）
   - comment 说清扣分点在哪里
   - better_answer 给一个学生可以直接学的示范回答（用他自己的经历改写，不要编造新经历，控制在 3 句话内）
5. summary 用 3-5 句话总结，先给一句整体判断，再指出最关键的一个短板和下一步最该做的一件事。
6. tags 按 7.8 回流画像：从这场面试里能确定的技能、知识盲区、沟通能力标签，只抽有依据的。
   维度只能用：兴趣/能力/技能/痛点/焦虑/认知。

输出要求：
- 只输出一个 JSON 对象，不要解释、不要 Markdown 代码块。
- JSON 结构：
{
  "overall_score": 68.5,
  "dimension_scores": {"沟通表达": 72, "逻辑思维": 65, "专业基础": 60, "项目经验": 70, "求职动机": 75},
  "strengths": ["自我介绍结构清楚，先说专业再说项目"],
  "improvements": ["项目描述只有结论，缺少可量化的结果"],
  "question_reviews": [
    {"question": "介绍你自己", "answer_summary": "按专业-项目-目标三段说", "score": 75, "comment": "条理不错但没有指向岗位要求", "better_answer": "我是计算机专业大三学生，做过一个校园二手交易平台，负责前端，目标是前端开发岗。"}
  ],
  "summary": "整体表达基本达标，专业深度不足。下一步优先补齐项目中的量化成果。",
  "tags": [{"dimension": "痛点", "label": "缺量化成果", "weight": 0.8, "evidence": "项目描述没有提到任何数字"}]
}
