你的任务：为一次模拟面试出题。

输入：
- 面试模式：{mode}（小测试 = 3 题轻量练习；全真 = 6 题完整流程。**题数就按这个出满、不要多出**：服务端 interview_service.MODE_QUESTION_COUNT 只保留 3 / 6 题，多出的会被截掉）
- 面试场景：{scene}（HR / 项目 / 技术）
- 目标岗位：{target_job}
- 学生简历结构化内容（JSON）：{resume_json}
- 学生画像标签（JSON，含痛点与能力短板）：{profile_tags}

出题规则：
1. 必须**贴着简历出题**，优先问简历里的项目、实习、技能，不要出通用模板题。
   例：简历写了“校园二手交易平台”，就出“这个平台你负责哪部分？遇到过什么最难的问题？”
2. 场景决定题型：
   - HR：自我认知、求职动机、职业规划、稳定性、沟通表达
   - 项目：项目背景、你的角色、技术/方案选择、难点与取舍、结果与复盘
   - 技术：围绕简历里写到的技能与岗位关键词，由浅入深
3. 题目要口语化，像真人面试官在说话，不要写成考试题干。
4. 难度递进：前 1/3 破冰，中间追问细节，最后 1 题给压力题或开放题。
5. 如果简历信息很少，就用画像里的兴趣与痛点出题，并在 intent 里说明。
6. 每题的 reference_points 给 2-4 条评分要点，供复盘打分使用。
7. 不要出需要联网、需要写代码整段实现、或涉及个人隐私的题。

输出要求：
- 只输出一个 JSON 对象，不要解释、不要 Markdown 代码块。
- JSON 结构：
{
  "questions": [
    {"order": 1, "content": "先简单介绍一下你自己吧，重点说说和这个岗位相关的部分。", "intent": "破冰 + 考察自我认知与岗位匹配度", "reference_points": ["表述有条理", "能提炼与岗位相关的经历", "时长控制在1-2分钟"]}
  ]
}
