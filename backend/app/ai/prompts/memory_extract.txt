你的任务：从这段对话里，提炼这个学生**自己说过的**关于“他想要什么、怕什么、为什么而努力”的信息。

【已有记忆（JSON，可能为空）】
{existing_memory}

【这段对话里学生说过的话（只有学生的话）】
{user_messages}

【硬规则】
1. 只能提炼学生**原话**里明确出现的内容；不许推断、不许补全、不许诊断、不许替他总结。
2. 每一条都必须带 `evidence`：从上面学生原话里**原样复制**的连续片段（不超过 30 字），一个字都不许改。
   把 evidence 放回原文里搜一次，必须能一字不差地搜到；搜不到就说明你改写了 —— 那就不输出这一条。
3. 找不到原话依据的，直接不输出；宁可少，不许编。
4. 不要输出“他可能”“他其实”“说明他”这类判断；只记录他说过的。
5. 同一件事不要输出多条；保留最具体的那一条。已有记忆里已经有的，不要重复；有新信息就补充。旧信息如果被这次对话明确推翻，以新的为准。

【字段含义】
- desired_life：他想要的生活（画面、关键词，例如“安稳”“有自己的时间”“不用看人脸色”）
- undesired_life：他明确不想过的生活
- values：他在意的东西（稳定 / 自由 / 钱 / 意义 / 关系 / 成长…）
- acceptable_costs：他愿意付出的代价
- unacceptable_costs：他绝不接受的代价
- motivation_sources：他为谁、为什么而努力
- uncertainty_tolerance：他对不确定性的态度
- role_models：他提到的想成为的人 / 榜样
- anti_models：他提到的绝对不想成为的人
- open_questions：他自己说还没想清楚的问题
- facts：他明确说过的稳定事实（年级、专业、城市、经济压力、家庭负担）

【输出】
只输出一个 JSON 对象，不要解释、不要 Markdown 代码块：
{
  "desired_life": [{"text": "想要安稳、有自己的时间", "evidence": "一眼望到头的生活活得很没意思"}],
  "undesired_life": [],
  "values": [],
  "acceptable_costs": [],
  "unacceptable_costs": [],
  "motivation_sources": [],
  "uncertainty_tolerance": [],
  "role_models": [],
  "anti_models": [],
  "open_questions": [],
  "facts": [{"text": "大三，计算机专业", "evidence": "我现在还在读书并且大三"}]
}
