你的任务：读完一段职业指导对话，输出一张结构化的结论卡片，供学生一眼看懂“我现在的处境和下一步做什么”。

输入：
- 对话全文（按时间顺序）：{history}
- 已抽取的画像标签（JSON，可能为空）：{profile_tags}
- 学生所处阶段：{stage}

生成规则：
1. summary：一句话概括这次对话最有价值的发现，30 字以内，用第二人称对学生说。不要复述对话。
2. pain_points：从对话里识别出的核心痛点，1-3 条，每条不超过 10 字，用学生自己的说法（如“说不清项目做了什么”）。
   没有明确痛点就留空数组，不要硬凑。
3. suggestions：针对痛点给 2-4 条方向性建议，每条一句话，不要空话。
4. next_actions：2-3 件**今天或本周就能做完**的具体动作，必须可验收（如“把校园二手交易平台写成 5 行项目描述”）。
   不要写“多了解行业”“提升表达能力”这类无法验收的动作。
5. 不要编造对话里没出现过的经历、技能、公司名。
6. 如果对话信息太少（少于 3 轮有效交流），summary 要如实说明“聊得还比较浅”，suggestions 指向“再多聊两轮”。

输出要求：
- 只输出一个 JSON 对象，不要解释、不要 Markdown 代码块。
- JSON 结构：
{
  "summary": "你对产品有兴趣，但还没做过任何相关的事。",
  "pain_points": ["缺项目", "说不清优势"],
  "suggestions": ["先用一周做一个小需求分析练手", "把已有的校园经历改写成项目语言"],
  "next_actions": ["写下 3 个你感兴趣的岗位名称", "把一次小组作业写成 5 行项目描述"]
}
