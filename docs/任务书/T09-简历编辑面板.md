## 风格硬规则（摘要，细节以规范为准）

- **一屏一个主角**：最大的 `Panel` 承担主要行动，其余内容用两列 7/5 支撑。禁止等高卡片一路堆下去。
- **讲人话**：数据翻译成陪伴语气，不要报表腔（"综合分""完成步骤""活跃天数"要换成人话）。
- **用色**：强调只用主墨 `text-primary`；`bg-accent` / `bg-secondary-fixed`（浅桃）只给小面积（chip、状态点、小按钮），不做大面积底色。全站已删除琥珀色（`text-secondary` / `bg-secondary` 不再表示强调）。
- **字号用语义阶**：`text-headline-xl`（页头）、`text-headline-sm`（区块标题）、`text-body-md`（正文）、`text-body-sm`（次要说明）、`text-caption`（小字）。禁止用 `text-xs` / `text-sm` 表达层级；禁止大面积 `text-muted-foreground`。`text-display` 只给首页式主角大数字，别的页面不用。
- **卡片**只用 `Panel`（白底、圆角、极轻阴影、无可见描边、内边距 20px）。卡内浅底块用 `<Panel inset>`。同一页只允许一种卡片外观和一种内边距数值。
- **页头**用 `PageHeader`（标题 26px/700，描述 14px、最宽 60ch，右侧最多一个实心按钮）。
- **按钮**：主 CTA 用 `<Button variant="warm" size="lg">`，组件自带尺寸和圆角，页面里不要再手写 `rounded-xl text-[15px]` 之类覆盖。次按钮 `variant="outline" size="sm"`。弱化动作 `variant="ghost" size="sm"`，放在页面底部一行。
- **空态**用 `EmptyState`，文案必须说真话，不能把零值文案套到有数据的场景。**加载态**用 `AIThinking`（或骨架）。**错误态**必须有原因和重试按钮，不允许静默空白。
- **页面宽度**：内容区 1040px（与首页一致），纵向间距 `gap-6`。窄栏流程页可以自己收窄（如 `max-w-3xl`）。
- **不能改的属性**：保留所有 `data-print` 属性；`resume-*` 类名不得改名（打印依赖它们）。
